# E-Commerce Business Intelligence & Profitability Analytics

## Project Overview

This project analyzes e-commerce sales data to identify business performance trends, profitability drivers, customer behavior, discount impact, and regional performance.

The project follows a complete Data Analyst workflow:

**Data Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

## Dataset

The project uses the Global Superstore dataset containing transactional e-commerce data across multiple markets, regions, product categories, customers, and orders.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Power BI
- Jupyter Notebook
- Git & GitHub

## Project Goals

- Analyze sales and profit performance
- Identify profitable and loss-making products
- Understand the impact of discounts on profitability
- Analyze customer and regional performance
- Build an interactive Power BI dashboard
- Generate actionable business insights
